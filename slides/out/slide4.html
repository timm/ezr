So calling sklearn is less code to write — 2.3× less. The 292 lines buy something else: every number in this deck came out of code you can read in an afternoon, with no version to pin, no wheel to build, and nothing that changes under you.

The four results, again: 4 points behind LightGBM at 6× the speed; a pick in the top 2% from 50 labels; 93% of the rare papers for a third of the reading. None of that needed the 2M lines.
