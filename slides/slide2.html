2. Few labels? Rank with a weak learner

x is free, y is dear: one label is one build, one benchmark, one expert hour. So never ask the model for a number — ask it for a shortlist. Optimization needs the tail, not the function, and a guesser too weak to predict is still strong enough to rank.
